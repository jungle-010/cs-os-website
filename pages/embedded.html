embedded

ocr definition

an OS built into a device that is designed to preform a specific task, usually stored in ROM and has either limited or no user interface.

benefits and drawbacks

benefits

  • small and efficient, little memory + power required - RISC based CPUs/SOCs can be used, decreases manufacturing cost
  • cheap to produce at a scale
  • reliable + quick to start

drawbacks

  • tied to specific hardware, so it is hard to upgrade/change/debug
  • cannot run general purpose software
  • code is often obfuscated

examples

  • washing machines
  • ECUs within vehicles

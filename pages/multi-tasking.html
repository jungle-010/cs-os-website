multi-tasking

ocr definition

where the OS allows for more than one running process/program at a time (may be using another thread or core)

benefits

  • users are able to be more productive by running several programs at once, such as a browser and a word processor
  • the cpu is may be used more efficiently because another task can run while one waits for an input/output

drawbacks

  • needs more ram to hold several programs at once
  • switching between tasks or contexts has an overhead that the computer may or may not be able to handle
  • too many processes may use up all system resources, slowing down the system, or crashing the system entirely.

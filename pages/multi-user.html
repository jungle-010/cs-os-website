multi-user

definition

where the OS allows for more than one user on the same machine with their own home directory (or user profile), files, permissions, and potentially programs.

benefits and drawbacks

benefits

  • resources such as printers, storage, and software are all shared; saving money
  • allows for user management and backups
  • in a server/enterprise environment, more than one user may connect (e.g. via RDP) to a machine, allowing for increased productivity

drawbacks

  • a user running heavy programs may increase load on the server and reduce performance for other logged in users
  • more users increases the vector of security risk
  • needs a system administrator and potentially increased disk size

examples

  • linux user management
  • windows active directory
